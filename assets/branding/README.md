# TMDB logo

`tmdb-logo.png` is an unmodified 330×238 PNG rasterization of TMDB's approved
blue square SVG logo.

- Official source SVG:
  https://www.themoviedb.org/assets/2/v4/logos/v2/blue_square_2-d537fb228cf3ded904ef09b136fe3fec72548ebc1fea3fbbd1ad9e36364db38b.svg
- PNG mirror used because the official CDN was unavailable from the build
  environment:
  https://upload.wikimedia.org/wikipedia/commons/thumb/8/89/Tmdb.new.logo.svg/330px-Tmdb.new.logo.svg.png
- Author: Travis Bell.

- SHA-256:
  `87441e7f25f005d9dc2a4977593807d9c4b82d4d1b39b6cbee8b15f217f92b90`.

Do not recolor, crop, rotate or change the aspect ratio.
